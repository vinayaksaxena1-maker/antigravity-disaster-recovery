# REA Standalone Sovereignty & Isolation Framework

## 1. Default State Anchor (Zero Amnesia Guarantee)
- **Primary Operational State**: Normal conversation aur daily tasks mein agent HAMESHA 100% Vinayak ke rules ke hisaab se chalega:
  - Developer Profile & Pragmatic Engineering (YAGNI, minimal code)
  - Token Efficiency (98% savings, sliced reads)
  - Developer Direct Response Mode
  - System Tools: Puppeteer, Artemis, Graphify
- **Anti-Confusion / Anti-Reset Lock**: 
  - REA ke existence ke chakkar mein agent kabhi bhi "Fresh Stage" ya default/amnesiac mode mein revert NAHI hoga.
  - Agent kabhi apne base rules, user profile, ya active MCPs ko bhool nahi sakta.

---

## 2. Activation Trigger (Chirag Ghisna)
- **Strict Single Trigger**: REA sirf aur sirf tab activate hoga jab user explicitly:
  - Slash command select kare: `/reverse-engineer-anything` ya `/rea`
- **Normal Tasks mein Absolute Freeze**: Jab tak upar diya gaya exact trigger na ho, REA ke 207 tools dormant rahenge. Agent normal work mein REA ko touch tak nahi karega.

---

## 3. Duniya 2: REA Native Realm (Jinn Mode / Temporary Sandbox)
Sirf `/reverse-engineer-anything` ke dauran:
- **Zero Interference**: User ke banaye rules (Token-saver, Sliced-reads, Pragmatic engineering) REA par lagu nahi honge.
- **Unrestricted Investigation**: REA chahe 400KB ho ya 4MB ka raw payload, AST bundle, ya decompilation data — bina kisi artificial token restriction ke poora analysis karega.
- **Official Tools Only**: REA apne official CLI commands (`npx rea-agents <subcommand>`) aur official patterns par chalega. Raw investigation data isolated scratch folder (`~/.gemini/antigravity/scratch/`) mein save hoga.
- **No Cross-MCP**: REA ke andar user ke baaki MCPs (Puppeteer, Artemis, Graphify) call nahi honge.
- **Handover & Disappear**: REA apna technical investigation poora karke final Evidence Blueprint dega, aur band ho jayega (Jinn wapas chirag mein).
