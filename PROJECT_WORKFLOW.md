# 🚀 The Perfect Vibe-Coding Master Workflow
> Antigravity me kisi bhi naye project ko 0 se production tak bina bugs aur context drift ke build karne ka standard blueprint.

---

## 🧭 The 4-Phase Execution Engine

```
[Phase 1: Brainstorm & Lock] ➔ [Phase 2: Tech & DB Spec] ➔ [Phase 3: Wave Plan] ➔ [Phase 4: Autonomous Build]
```

---

## 📋 Copy-Paste 5-Prompt Checklist

Jab bhi koi naya project shuru karna ho, bas ye 5 prompts step-by-step chat me bhejo:

### 🔹 Step 1: Requirements & User Flow Lock
```text
/grill-me Maine ek naya project socha hai: [Project Idea / Name yahan likho].
Iska PRD aur Mermaid App Flow finalize karne ke liye mujhse 4-5 sharp questions poocho.
```
> **Result**: AI tumhara interview lega, faltu assumptions hatayega (YAGNI), aur screen navigation map draw karega.

---

### 🔹 Step 2: UI/UX Design System
```text
Is project ka UI/UX Design Brief lock karo.
Layout: [Bento Grid / Centered Card / Vertical List]
Style: [Minimalist Clean / Glassmorphism / Aurora Glow / Neo-Brutalism]
Color tokens, typography scale aur screen wireframes batao.
```
> **Result**: `ui-ux-pro-max` trigger hoga aur pure app ke colors, fonts aur component standards fix kar dega.

---

### 🔹 Step 3: Technical Architecture & Database Schema
```text
/boost Is project ka TRD (Tech Specs) aur Database Schema design karo.
Stack: [Next.js / Flutter / FastAPI / etc.]
Tables, fields, relations (1:N, M:N) aur API contracts lock karo.
```
> **Result**: `/boost` deep reasoning on karega; database models aur API contracts fix honge taaki baad me koi schema rework na ho.

---

### 🔹 Step 4: Atomic Implementation Plan
```text
/plan Pichle specs ke base par step-by-step wave-by-wave Implementation Plan banao.
Har task atomic aur testable hona chahiye.
```
> **Result**: `concise-planning` pure project ko 4-5 executable waves me divide karega with checkboxes.

---

### 🔹 Step 5: Autonomous Execution & Verification
```text
/goal Implementation Plan ke Wave 1 se shuru karo aur step-by-step execute karo.
Browser testing ke liye puppeteer use karo.
```
> **Result**: `/goal` mode me agent files banayega, code likhega, tests chalayega aur Puppeteer se UI verify karega.

---

## 🛡️ Quick Decision Rules

1. **Layout Rule**:
   - Multiple cards/metrics ➔ **Bento Grid**
   - Single task/form ➔ **Centered Card**
   - Infinite scroll/chat ➔ **Vertical List**
2. **Style Rule**:
   - Serious / SaaS ➔ **Minimalist Clean**
   - Modern / Sleek ➔ **Glassmorphism**
   - AI / Crypto / Hero ➔ **Aurora Glow**
   - Fun / Gamified ➔ **Claymorphism**
3. **Engineering Filter (Ponytail)**:
   - Always ask: *"Kya ye feature sach me chahiye? Kya stdlib se ho sakta hai?"*
